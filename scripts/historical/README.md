# Historical n=5 audit scripts

These phase-26, H-Qb, H-orb and H-coc scripts are retained for auditability
of the superseded n=5 programme. They are not part of the active proof chain,
are not run by `scripts/run_all.py`, and must not be cited as current evidence.
They are archival snapshots moved out of the active layout; their old relative
paths and imports are not guaranteed to run after relocation.
The former unrestricted single-residual reduction was withdrawn because its
boundary-role, metric-prism and setwise-to-pointwise steps were not
established. The active n=5 result is the conditional BRH theorem in the
repository root.
